# Enterprise CI/CD Pipeline with GitHub Actions

This project demonstrates an **enterprise-level CI/CD pipeline** using **GitHub Actions**, **Docker**, and a **self-hosted runner**.  
Every push to the `main` branch automatically triggers build, test, security scan, and deployment stages.

---

## Tech Stack
- **GitHub Actions** – CI/CD automation
- **Docker** – Application containerization
- **Self-hosted Runner (WSL Ubuntu)** – Enterprise-style execution
- **Git** – Version control
- **Linux (Ubuntu)** – Runner environment
